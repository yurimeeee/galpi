# 갈피 (Galpi) 기능 명세서

> 책 속 문장을 "갈피"로 기록하고 독서 습관을 관리하는 모바일 앱.
> 이 문서는 기존 Expo 구현(2026-11 기준)을 분석해 **기술 스택과 무관하게** 기능·화면·데이터 모델을 정리한 것이다. 새 프로젝트에서 처음부터 다시 개발할 때 요구사항 원본으로 사용한다.

---

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | 갈피 (Galpi) — "책갈피"에서 따온 이름. 저장한 문장 하나를 "갈피"라고 부른다 |
| 한 줄 소개 | 책 속에서 나만의 갈피를 찾다 |
| 핵심 가치 | ① 문장 수집(직접 입력·카메라 스캔·페이지 사진) ② 독서 습관 트래킹(타이머·목표·스트릭·뱃지) ③ 감성 리포트(월간·연간 통계, 공유 카드) |
| 플랫폼 | iOS / Android / 웹(모바일 뷰 중심, 데스크톱은 중앙 정렬 컨테이너) |
| 언어 | 한국어 단일 |
| 테마 | 라이트 / 다크 / 기기 설정 따름 |
| 계정 | 이메일+비밀번호, Google 로그인. 모든 데이터는 사용자별 격리 |

### 용어

| 용어 | 뜻 |
|---|---|
| 갈피 | 사용자가 저장한 문장 1개 (인용문 + 페이지 + 메모 + 태그 + 입력 방식) |
| 서재 | 사용자가 등록한 책 목록 |
| 읽는 중 / 완독 / 읽고 싶은 | 책의 3가지 상태 |
| 스트릭 | 연속으로 독서 활동(갈피 저장 또는 타이머 기록)을 한 일수 |
| 모음집 | 태그 기준으로 책을 가로질러 묶은 갈피 그룹 |
| 리포트 | 월간·연간 통계를 이미지 카드로 발행한 것 |
| 연말 결산 | 한 해의 독서를 스토리 슬라이드로 보여주는 화면 |

## 2. 데이터 모델

모든 컬렉션은 `users/{uid}/` 아래에 두고, 본인만 읽기/쓰기 가능하다.

### 2.1 Book (책) — `users/{uid}/books/{bookId}`

| 필드 | 타입 | 설명 |
|---|---|---|
| id | string | 문서 ID |
| title | string | 제목 (필수) |
| author | string | 저자. 비어 있으면 `"저자 미상"` |
| status | `'reading' \| 'done' \| 'wish'` | 읽는 중 / 완독 / 읽고 싶은. 신규 등록 기본값 `wish` |
| rating | number 0~5 | 별점. 같은 별을 다시 누르면 0 |
| galpiCount | number | 이 책에 저장된 갈피 수 (갈피 추가/삭제 시 자동 증감) |
| progress | number 0~100 | 진행률. `furthestPage / totalPages`로 자동 계산 |
| totalPages | number? | 총 페이지. 사용자 직접 입력 (예스24 API는 페이지 수를 제공하지 않음) |
| furthestPage | number? | 갈피가 참조한 가장 큰 페이지 번호 (갈피 저장 시 자동 갱신) |
| coverUrl | string? | 표지 URL (예스24 표지 `https://image.yes24.com/goods/{itemId}/L` 또는 사용자 업로드) |
| genre | string? | 카테고리 경로(`>` 구분), 예: `국내도서>소설/시/희곡`. 예스24 `goodsSortNm`의 `-`를 `>`로 정규화 |
| accent | `'blue' \| 'green' \| 'yellow' \| 'ink'` | 책등(spine) 색. 등록 순서대로 4색 순환 자동 배정 |
| completedAt | string? `"YYYY.MM.DD"` | 상태가 `done`이 된 날짜. 다른 상태로 바꾸면 삭제 |
| review | string? | 완독 후 짧은 총평 |
| order | number | 서재 수동 정렬 순서 (0부터). 신규 책은 맨 뒤 |

### 2.2 Sentence (갈피) — `users/{uid}/sentences/{sentenceId}`

| 필드 | 타입 | 설명 |
|---|---|---|
| id | string | 문서 ID |
| bookId | string | 소속 책 |
| quote | string | 인용 문장 (페이지 사진 모드에선 빈 문자열 가능) |
| page | number | 페이지 번호 |
| memo | string? | 생각/메모 |
| tags | string[]? | 태그. 최대 5개, 각 12자, `#` 접두어 제거 |
| type | `'text' \| 'scan' \| 'photo'` | 직접 입력 / 카메라 스캔 / 페이지 사진 |
| photoUrl | string? | 페이지 사진 모드일 때 업로드한 이미지 URL |
| favorite | boolean? | 즐겨찾기(별) |
| date | string `"YYYY.MM.DD"` | 저장일 (서버가 아닌 클라이언트 로컬 날짜) |
| hour | number 0~23? | 저장 시각(시). 시간대 통계용 |

**저장 시 부수 효과 (트랜잭션)**
- 책의 `galpiCount += 1`
- `page > book.furthestPage`이면 `furthestPage` 갱신, `totalPages`가 있으면 `progress` 재계산
- 삭제 시 `galpiCount -= 1`

### 2.3 사용자 설정 — `users/{uid}/userSettings/{docId}`

**`readingGoals`**

| 필드 | 기본값 | 설명 |
|---|---|---|
| dailyMinutes | 30 | 하루 독서 시간 목표(분), 5분 단위 |
| monthlyBooks | 3 | 월 완독 목표(권) |
| yearlyBooks | 36 | 연 완독 목표(권) |

**`readingLog`** — `{ "YYYY.MM.DD": minutes }` 맵. 타이머 세션 종료 시 당일 분이 누적된다.

**`preferences`** (알림 설정)

| 필드 | 설명 |
|---|---|
| dailyReminderEnabled | 매일 독서 알림 on/off |
| dailyReminderTime | `"HH:mm"`, 기본 `21:00` |
| streakRiskReminderEnabled | 스트릭 위험 알림 on/off (22:00 고정) |
| onThisDayEnabled | 1년 전 오늘의 갈피 알림 on/off (20:00 고정) |
| expoPushToken | 푸시 토큰 (저장만, 현재 서버 발송 없음) |

### 2.4 사용자 프로필 — `users/{uid}`
인증 제공자의 `displayName`, `photoURL`을 사용. 프로필 수정 시 인증 프로필 + 이 문서를 함께 갱신.

### 2.5 스토리지
- `users/{uid}/sentence-photos/{ts}.jpg` — 페이지 사진
- `users/{uid}/book-covers/{ts}.jpg` — 직접 등록한 표지
- `users/{uid}/profile/{ts}.jpg` — 프로필 사진

### 2.6 백업 파일 포맷 (JSON)
```json
{ "version": 1, "exportedAt": "ISO-8601", "books": [Book...], "sentences": [Sentence...] }
```

## 3. 파생 로직 (순수 함수)

| 이름 | 입력 | 규칙 |
|---|---|---|
| 활동일 집합 | sentences, readingLog | 갈피를 저장했거나 타이머 분 > 0 인 날짜들 |
| 현재 스트릭 | 활동일 집합 | 오늘부터 거꾸로 연속 일수. **오늘 활동이 없으면 어제부터 센다** (하루가 끝나지 않았으므로 0으로 리셋하지 않음) |
| 최고 스트릭 | 활동일 집합 | 역대 최장 연속 일수 |
| 오늘 독서 분 | readingLog | `readingLog[오늘]` |
| 월/연 완독 수 | books | `completedAt`이 해당 월/연인 `done` 책 수 |
| 연간 독서 분 | readingLog | 해당 연도 분 합계 |
| 연도 내 최고 스트릭 | 활동일, year | 해당 연도 안에서의 최장 연속 |
| 올해 가장 많이 담은 책 | sentences, books, year | 해당 연도 갈피 수가 가장 많은 책 + 대표 문장(즐겨찾기 우선, 없으면 최신) |
| 1년 전 오늘 | sentences, today | 같은 월/일에 과거 연도 저장된 갈피. 정확히 1년 전 우선, 없으면 가장 최근 과거 연도 |
| 가장 활발한 시간대 | sentences | `hour` 최빈값. 표본 5개 미만이면 null (알림 시간 제안용) |
| 요일/시간대 패턴 | sentences, year, month? | 요일별 갈피 수(7), 시간대 구간별 수, 각각의 최빈 인덱스 |
| 상위 장르 | sentences, books, year, month? | 해당 기간 갈피를 남긴 책들의 장르 빈도 상위 3개 |
| 연간 히트맵 | sentences, year | 주×요일 격자, 각 칸 = 그날 갈피 수 |
| 대표 문장 | sentences, 기간 | 기간 내 즐겨찾기 갈피 우선, 없으면 최신 |
| 뱃지 진행 | 완독 수, 총 갈피 수, 최고 스트릭 | §9 뱃지 표 참고. 한 번 달성하면 유지 |
| 책 상태 필터 카운트 | books | 전체/읽는 중/완독/읽고 싶은 각 개수 |

## 4. 외부 연동 (서버 함수)

클라이언트에 비밀키를 두지 않기 위해 서버리스 함수 2개를 둔다.

| 엔드포인트 | 메서드 | 입력 | 출력 | 비고 |
|---|---|---|---|---|
| `/api/yes24-book-search` | GET | `query` | `{ books: [{ itemId, title, author, publisher, thumbnail, isbn, contents, genre }] }` | 예스24 `GET https://apis.yes24.com/v1/goods/itemList?query=&page=1&pageSize=20&category=BOOK`, 헤더 `X-Api-Key`. `goodsType === '도서'`만 남기고, `goodsSortNm`의 `-` 구분자를 `>`로 바꿔 `genre`로 전달(기존 데이터와 동일 형식). `contents`는 `contentDetail.bookIntroduction`. 응답은 `{ success, message, errorCode, data: { items, totalCount } }` |

예스24 API는 총 페이지 수를 제공하지 않는다(itemDetail·content·author 모두 없음). 검색으로 추가한 책의 `totalPages`는 비어 있고, 책 상세의 진행도 편집에서 사용자가 직접 입력한다. (알라딘 Open API 종료 전에는 `ItemLookUp`으로 자동 채웠다.)
| `/api/ocr` | POST | `{ image: "data:image/..." }` | `{ sentence: string, tokens: string[] }` | 멀티모달 LLM에 책 페이지 사진을 보내 밑줄/하이라이트 또는 가장 두드러진 문단을 그대로 추출. 따옴표·설명 없이 문장만. 못 읽으면 빈 문자열. 30초 제한 |

OCR 시스템 프롬프트(원문):
> 너는 책 페이지 사진에서 문장을 읽어내는 OCR 도우미야. 사용자가 보내는 사진은 종이책의 한 페이지를 촬영한 것이고, 사진 중앙의 밑줄/하이라이트 영역이나 가장 두드러지는 한 문단의 문장을 최대한 정확하게 그대로 옮겨 적어. 따옴표, 설명, 페이지 번호, 서론 문구 없이 인식된 문장만 출력해. 문장을 전혀 읽을 수 없으면 빈 문자열만 출력해.

필요 환경 변수: Firebase 클라이언트 설정 7종, Google OAuth 웹 클라이언트 ID, `YES24_API_KEY`(서버 전용), LLM 게이트웨이 키(서버 전용).

## 5. 내비게이션 구조

```
(게이트)  index → loading | onboarding | login | signup | app
│
├─ /onboarding                 온보딩 3슬라이드
├─ /login                      로그인
├─ /signup                     회원가입
│
├─ (tabs)  하단 탭 4칸: 내 서재 · [＋] · 독서 통계 · 마이페이지
│   ├─ /library                내 서재 (홈)
│   ├─ /stats                  독서 통계
│   └─ /mypage                 마이페이지
│
├─ /book/[id]                  책 상세
├─ /add-book        (modal)    책 추가
├─ /add-sentence    (modal)    갈피 남기기      ?bookId=
├─ /edit-sentence              갈피 수정/삭제   ?sentenceId=
├─ /reading-timer              독서 타이머      ?bookId=
├─ /favorites                  즐겨찾는 갈피
├─ /collections                태그 모음집
├─ /reading-goal               독서 목표
├─ /badges                     독서 업적
├─ /year-review                연말 결산        ?year=
├─ /notification-settings      알림 설정
├─ /theme-settings             테마
├─ /linked-accounts            소셜 계정 연동
├─ /data-backup                데이터 백업 및 복구
├─ /notices                    공지사항
├─ /terms                      이용약관
└─ /privacy                    개인정보 처리방침
```

**게이트 규칙**
- 앱 시작 시 인증 상태 확인 전까지 `loading` (스플래시 유지)
- 미로그인 + 첫 실행 → `onboarding`, 미로그인 + 온보딩 완료 → `login`
- 로그인됨 → `app` (`/library`로 리다이렉트)
- 로그아웃 시 `login`으로

**전역 오버레이 (모든 화면 위)**
- **플로팅 타이머 위젯**: 타이머 세션이 활성이고 현재 화면이 `/reading-timer`가 아닐 때 표시. 원형 진행도 + 남은 시간, 탭하면 타이머 화면으로. 드래그로 위치 이동 가능. 완료 시 "완료!" 표시
- **실행취소 스낵바**: 삭제 후 하단에 "책을 삭제했어요 / 갈피를 삭제했어요 [실행취소]". 화면을 이동해도 유지, 일정 시간 후 자동 사라짐. 실행취소 시 원래 ID로 복원(책은 소속 갈피까지)
- **하단 탭 바**: 4칸. 가운데 `＋`는 탭이 아니라 "추가 선택 시트"를 연다

**추가 선택 시트 (＋ 버튼)**
1. **갈피 남기기** — 현재 "읽는 중"인 책(없으면 첫 번째 책)으로 바로 이동. 아래에 책 목록이 있어 다른 책을 골라 갈피 남기기 가능
2. **독서 타이머 시작**
3. **새 책 추가하기**
- 책이 하나도 없으면 안내 문구 + 새 책 추가만 가능

## 6. 화면별 명세

### 6.1 온보딩 `/onboarding`
- 가로 스와이프 3슬라이드, 페이지 인디케이터, 우상단 "건너뛰기"
- 슬라이드 (각각 일러스트 + 악센트색)

| # | 악센트 | 제목 | 설명 |
|---|---|---|---|
| 1 | yellow | 문장을 스캔해 갈피로 소장하세요 | 책 속 인상 깊은 문장을 카메라로 스캔하면 나만의 갈피가 되어 차곡차곡 쌓여요. |
| 2 | green | 달력과 책장에 쌓이는 독서 기록 | 읽은 날짜와 완독한 책이 달력과 책장에 차곡차곡 기록돼요. |
| 3 | blue | 감성적인 월간·연간 리포트 | 한 달, 한 해의 독서를 담은 리포트를 만들고 친구와 공유해요. |

- 마지막 슬라이드 또는 건너뛰기 → 온보딩 완료 플래그 저장 → 로그인 화면

### 6.2 로그인 `/login`
- 로고 중심 레이아웃
- 이메일 / 비밀번호 입력 → "로그인"
- 구분선 "또는" → "Google로 계속하기"
- 하단 "아직 계정이 없으신가요? **회원가입**"
- 실패 시 인증 에러를 한국어 메시지로 변환해 표시 (잘못된 비밀번호, 존재하지 않는 계정, 네트워크 오류 등)

### 6.3 회원가입 `/signup`
- 닉네임 / 이메일 / 비밀번호(6자 이상) / 비밀번호 확인
- 약관 동의 체크 (이용약관·개인정보 처리방침 링크 → 각 화면)
- 실시간 검증: 이메일 형식, 비밀번호 일치. 모두 충족 + 동의 시에만 가입 버튼 활성
- 가입 성공 → 닉네임을 프로필에 저장 → 서재로

### 6.4 내 서재 `/library` (홈 탭)

**헤더 영역**
- 우측 아이콘 3개: 태그 모음집, 즐겨찾는 갈피, 검색
- 에디토리얼 헤드라인: "지금까지 모은 문장 / **N개의 갈피**" (숫자에 노란 하이라이트)
- **오늘 스트립**: 현재 스트릭 일수 · 오늘 독서 분 / 목표 분 · "타이머 시작" 버튼
- **지금 읽는 중 대표 카드**: `reading` 상태 책 1권(없으면 생략). 책 악센트 색 배경, 표지 + 제목/저자 + 대표 문장 + 진행률 바. 탭 → 책 상세

**서재 섹션**
- 섹션 제목 "내 서재" + 뷰 토글(리스트 / 카드 그리드) + 순서 편집 버튼
- 상태 필터 칩: 전체 / 읽는 중 / 완독 / 읽고 싶은 (각 개수 표시). 필터 적용 중 "전체보기" 링크
- 보조 필터 칩 행: **장르**(책의 장르 대분류 중복 제거, 가나다순), **완독 연도**(내림차순). 단일 선택, 다시 누르면 해제
- 리스트 뷰: 표지(2:3) + 제목 + 저자 + 상태 + 갈피 수 + 진행률
- 카드 뷰: 표지 그리드(폭에 따라 3~5열), 표지 위 갈피 수 뱃지
- 책 탭 → 상세. 책이 없으면 빈 상태 + "새 책 추가하기"

**검색 모드** (검색 아이콘)
- 상단 입력창 "책 제목, 작가, 또는 갈피 문장 검색"
- 결과 두 그룹: **책**(제목·저자 매칭), **갈피**(인용문·메모·태그 매칭, 일치 구간 하이라이트). 갈피 결과 탭 → 갈피 수정 화면
- 보조 필터(장르·연도)는 검색에도 함께 적용
- 빈 결과 문구: `'검색어'에 대한 검색 결과가 없어요` / `조건에 맞는 책이나 갈피가 없어요` / 초기 `책 제목, 작가, 또는 문장으로 검색해보세요`

**순서 편집 모드**
- 제목 "서재 순서 편집", 안내 "오른쪽 손잡이를 눌러 드래그하면 순서를 바꿀 수 있어요"
- 드래그 앤 드롭으로 재정렬. 낙관적 반영 후 저장, 실패 시 원복 + 안내
- 완료 버튼으로 종료

**로딩**: 첫 데이터 도착 전 스켈레톤. 로컬 캐시가 있으면 즉시 캐시 렌더 후 실시간 데이터로 교체

### 6.5 책 상세 `/book/[id]`

**헤더**: 뒤로 / 독서 타이머 / 갈피 카드로 공유 / 책 삭제

**히어로**: 큰 표지(그림자) + 제목 + 저자 + 장르
- **별점** 5개 (탭으로 설정, 같은 별 재탭 시 0)
- **상태 칩** 3개: 읽는 중 / 완독 / 읽고 싶은. `reading`으로 전환하는 순간 "독서 시작" 알림 트리거(매일 알림이 켜져 있으면 알림 스케줄 보장)
- **총평**: 없으면 "이 책은 어땠나요? 총평을 남겨보세요" 안내 + 작성 버튼, 있으면 본문 + 수정 버튼 → 총평 모달(멀티라인 입력)
- **지표 행** (구분선 분할): 진행도 % (탭 → 진행도 모달) · 남긴 갈피 N개 · 수집 문장 N개

**진행도 모달**
- 총 페이지 / 현재 페이지 입력 + 슬라이더. 진행률 미리보기
- 저장 시 `totalPages`, `furthestPage`(총 페이지 초과 시 클램프), `progress` 갱신

**갈피 목록** ("수집한 갈피 목록")
- 각 항목: 좌측 책등 색 바, 인용문, 페이지 뱃지 `P. 208`(tabular-nums), 메모, 태그 칩, 입력 방식 라벨, 날짜, 즐겨찾기 별 토글
- 페이지 사진 타입은 썸네일 표시
- 탭 → 갈피 수정 화면
- 비어 있으면 빈 상태

**하단 고정 CTA**: "갈피 남기기" → `/add-sentence?bookId=`

**공유 플로우**
- 공유 아이콘 → 갈피가 1개면 바로 카드 모달, 여러 개면 "공유할 갈피 선택" 시트(즐겨찾기 우선 정렬) → 카드 모달
- **갈피 카드 모달** ("갈피 카드 만들기"): 테마 3종 `ink`(검정 바탕) / `paper`(흰 바탕) / `accent`(책 악센트색), 비율 `1:1 인스타 피드` / `9:16 스토리`. 카드에는 인용문·책 제목·저자·페이지·"갈피" 워터마크. 액션: **이미지 저장**(사진 보관함) / **SNS 공유하기**(OS 공유 시트). 웹은 다운로드

**삭제**: 확인 다이얼로그 "책을 삭제할까요? / "제목"과 여기에 남긴 모든 갈피가 함께 삭제돼요." → 삭제 후 실행취소 스낵바 (책 + 갈피 전체 복원)

**로딩/404**: 데이터 로딩 전 스켈레톤, 로딩 후에도 없으면 서재로 리다이렉트

### 6.6 책 추가 `/add-book` (모달 프레젠테이션)

탭 2개: **검색** / **직접 입력**

**검색**
- 입력 "책 제목이나 저자를 검색해보세요", 검색 키로 실행
- 상태: 초기 안내 / 로딩 / 결과 없음 "검색 결과가 없어요." / 오류
- 결과 행: 썸네일 + 제목 + 저자 + 출판사 + "추가" 버튼
- 추가 시 → 페이지 수 조회(lookup) → 책 생성(제목·저자·표지·총페이지·장르). 처리 중 해당 행 로딩 표시. 성공 시 닫기

**직접 입력**
- 표지: 사진 찍기 / 앨범에서 선택 (업로드 후 URL 저장), 없으면 책등 색 폴백
- 제목(필수) / 저자(선택, 기본 "저자 미상") / 장르(프리셋 칩 선택 또는 직접 입력, 선택) / 총 페이지(선택)
- "책 추가하기" 버튼, 저장 중 로딩

### 6.7 갈피 남기기 `/add-sentence?bookId=` (모달 프레젠테이션)
- 헤더에 대상 책 제목 표시. `bookId` 없으면 "읽는 중" 책, 그것도 없으면 서재로
- 입력 방식 탭 3개:

**① 직접 입력 (`text`)**
- 문장(멀티라인, "마음에 담고 싶은 문장을 적어주세요.") · 페이지(숫자) · 메모(선택) · 태그

**② 카메라 스캔 (`scan`)**
- 권한 없으면 "카메라 허용하기"
- 라이브 프리뷰 → 촬영 → 이미지 축소/압축 → OCR API 호출("문장 인식 중...")
- 결과를 **단어 토큰 칩**으로 보여주고, 사용자가 탭하여 포함할 토큰을 선택/해제 → 선택된 토큰이 문장 입력에 합쳐짐. 문장 직접 수정 가능
- "다시 촬영" 가능. 인식 실패 시 오류 메시지 + 재촬영
- 페이지 · 메모 · 태그 동일

**③ 페이지 사진 (`photo`)**
- "책 페이지를 통째로 기록해요" 안내, 사진 찍기 / 앨범에서 선택 / 다시 선택
- 사진은 스토리지에 업로드하고 `photoUrl` 저장. 문장은 비워도 됨
- 페이지 · 메모("이 페이지를 기억하고 싶은 이유를 적어보세요. (선택)") · 태그

**태그 입력 공통**
- 칩 형태, 최대 5개, 12자, `#` 제거, 중복 불가
- 기존 사용 태그를 추천 칩으로 표시(사용 빈도순), 탭으로 추가

**저장**: 하단 고정 저장 바. 모드별 필수값 검증(문장/인식 문장/사진). 저장 후 닫기

### 6.8 갈피 수정 `/edit-sentence?sentenceId=`
- 책 정보 표시(수정 불가), 문장 / 페이지 / 메모 / 태그 수정
- 페이지 사진 타입이면 사진 미리보기 유지
- 저장 → 책의 `furthestPage`/`progress` 재계산
- 삭제 → 실행취소 스낵바 (원래 ID로 복원)

### 6.9 즐겨찾는 갈피 `/favorites`

- 각 카드: 책 표지·제목, 인용문, 페이지, 즐겨찾기 해제 버튼
- 탭 → 갈피 수정. 비어 있으면 빈 상태

### 6.10 모음집 `/collections`

- 태그가 없으면 안내

### 6.11 독서 타이머 `/reading-timer?bookId=` (뽀모도로)

**설정 상태 (세션 시작 전)**
- 읽을 책 선택 카드(표지 + 제목, "책 변경" → 책 선택 시트)
- 프리셋 칩: `25분 독서 / 5분 휴식` · `50분 독서 / 10분 휴식` · `자율 설정`(집중 분 스테퍼, 휴식 3분 고정)
- 총 4세션. "시작"

**진행 상태**
- 큰 원형 타이머(남은 시간, 진행 링), 현재 단계 라벨(집중/휴식), 세션 n/4
- 일시정지/재개, 리셋, "독서 종료"
- 단계 전환은 **앱 루트에서 1초마다 구동**되어 다른 화면으로 가도 계속 진행. 종료 시각을 epoch로 저장해 백그라운드 복귀 시 정확히 계산
- 중간에 "갈피 남기기" 진입 가능(세션 유지)

**세션 요약 모달** (4세션 완료 또는 독서 종료 시)
- 총 집중 시간, 완료 세션 수, 이번 세션 동안 수집한 갈피 수(시작 시점 대비 `galpiCount` 증가분)
- "읽은 페이지 수" 입력(선택) → 책 진행도 반영
- "독서 기록에 반영하기" → `readingLog[오늘] += 집중 분` → 타이머 종료 → 뒤로

### 6.12 독서 통계 `/stats` (탭)

상단: 제목 "독서 통계" + 리포트 발행 버튼. 기간 토글 **월간 / 연간**, 좌우 화살표로 이동

**월간**
- 지표 카드 3개: 완독한 책 · 남긴 갈피 · 읽은 날 (전월 대비 증가분 뱃지, 증가일 때만)
- **독서 달력**: 보기 토글 `날짜` / `표지`. 날짜 보기는 활동일 표시, 표지 보기는 그날 갈피를 남긴 책 표지를 셀에 표시
- "주로 읽는 요일" 분포 바(7), 최빈 요일 강조. 기록 없으면 "아직 이달의 독서 기록이 없어요."
- "주로 기록하는 시간대" 분포 바
- "이달의 취향": 상위 장르 3개 칩
- "이달 갈피를 남긴 책": 책 + 갈피 수 목록
- 이달 대표 문장 카드
- 푸터 버튼 "이달의 독서 리포트 발행하기"

**연간**
- 지표 카드 3개(전년 대비)
- "연간 독서 활동" 히트맵(주×요일, 적음→많음 범례)
- 주로 읽는 요일 / 시간대
- "올해 가장 많이 담은 책" 카드(표지 + 대표 문장)
- 올해의 취향(장르)
- 연말 결산 진입 버튼 → `/year-review?year=`
- 푸터 "올해의 독서 리포트 발행하기"

**리포트 발행 모달** ("독서 리포트 발행")
- 비율 `1:1 인스타 피드` / `9:16 스토리`
- 카드 내용: 기간 제목, 지표 3개(완독한 책 권 / 수집한 갈피 개 / 읽은 날 일), 주로 읽는 요일 미니 차트, 기록 시간대, 취향, 이달 완독한 책 표지들, (연간) 히트맵, 워터마크
- "이미지 저장하기" / "SNS 공유하기"
- 스켈레톤: 데이터 도착 전

### 6.13 연말 결산 `/year-review?year=`
- 세로 스와이프/페이지 스토리 카드. 페이지 인디케이터
- 카드 순서:
  1. 인트로: "{닉네임}님의 {year}년", 완독 N권 · 갈피 N개
  2. 올해 완독한 책: 표지 그리드
  3. 읽은 날: 읽은 날 수 + 요일 분포, 최빈 요일
  4. 스트릭: 올해 최고 연속 N일 + 히트맵
  5. 총 독서 시간: 타이머 누적 분(시간 단위 환산)
  6. 올해의 취향: 장르 상위 3 ("장르 정보가 있는 책이 쌓이면 여기에 취향이 나타나요.")
  7. 올해 가장 많이 담은 책: 표지 + 대표 문장
  8. 요약 카드: 지표 모음 + 워터마크 "책 속에서 나만의 갈피를 찾다 · 갈피" + **이미지 저장** / **공유하기**
- 기록이 없으면 "아직 {year}년의 독서 기록이 없어요. 갈피를 남기면 결산이 여기 채워져요."

### 6.14 독서 목표 `/reading-goal`
- **스트릭 히어로**(노란 배경): "연속 독서 N일째", 최근 7일 요일 점(활동일 채움), 최고 기록
- "나의 목표 진행" 리스트 그룹 3행: 오늘 독서 시간(분/목표) · 이달 완독(권/목표) · 올해 완독(권/목표), 각 진행률 바
- "읽은 날" 미니 달력
- "스트릭 배지": 스트릭 카테고리 뱃지 4종 진행 상태
- "목표 수정" → **목표 설정 모달**: 스테퍼 3개 (하루 분: 5단위, 월 권: 1, 연 권: 1). 낙관적 저장, 실패 시 원복

### 6.15 독서 업적 `/badges`
- 3카테고리 × 4단계 = 12개 뱃지 그리드. 달성/미달성 구분, 제목 + 설명
- (뱃지 표는 §9)

### 6.16 마이페이지 `/mypage` (탭)
- **프로필 카드**(파란 배경): 아바타(사진 또는 이니셜) · 닉네임 · 이메일 · 편집 버튼 → 프로필 수정 모달
- 요약 칩 3개: 책 N권 · 갈피 N개 · 스트릭 N일
- **독서 목표 진입 카드**(노란): "목표와 스트릭을 확인해 보세요" → `/reading-goal`
- 설정 그룹 (hairline 구분 리스트)

| 그룹 | 행 | 동작 |
|---|---|---|
| 계정 및 보안 | 비밀번호 변경 | 모달 (이메일 계정만) |

- 하단 텍스트 버튼: **로그아웃** / **회원탈퇴**(빨강)

**프로필 수정 모달**: 사진 선택 / 기본 이미지로, 닉네임(2~12자, 특수문자 제외) → 인증 프로필 + 사용자 문서 갱신
**비밀번호 변경 모달**: 현재 비밀번호 → 재인증 → 새 비밀번호(8자 이상) + 확인
**회원 탈퇴 모달**: 경고 문구, 이메일 계정은 현재 비밀번호 재인증(소셜은 재로그인) → 모든 Firestore 문서 + 스토리지 파일 삭제 → 인증 계정 삭제 → 로그인 화면

### 6.17 알림 설정 `/notification-settings`
웹에서는 로컬 알림 미지원 안내. 네이티브는 권한 요청 후 로컬 스케줄 알림.

| 항목 | 설명 |
|---|---|
| 매일 독서 알림 | 토글 + 알림 시간 피커(기본 21:00), 매일 반복 |
| 시간 제안 | 갈피를 가장 많이 남긴 시간대가 현재 설정과 다르면 "가장 많이 기록한 시간대는 N시예요. 이 시간으로 바꿔볼까요?" + 적용 / 닫기 |
| 스트릭 위험 알림 | 토글. 오늘 활동이 없고 **살아있는 스트릭이 있을 때만** 당일 22:00 1회성 알림 예약. 활동이 생기면 즉시 취소. 앱 실행 시마다 재계산 |
| 1년 전 오늘의 갈피 | 토글. 오늘 날짜에 과거 저장된 갈피가 있으면 20:00 1회성 알림(문장 + 책 제목). 앱 실행 시마다 재계산 |
| 알림 미리보기 | 노란 카드로 오늘 발송될 알림 문구 미리보기 |

설정 값은 `userSettings/preferences`에 저장. 서버 푸시 없이 클라이언트 로컬 알림만 사용하므로 앱을 열지 않은 날은 알림이 없을 수 있음(알려진 제약).

### 6.18 테마 `/theme-settings`
라디오 3개: 기기 설정(기기의 화면 모드를 따라가요) / 라이트(항상 밝은 화면으로 보여줘요) / 다크(항상 어두운 화면으로 보여줘요). 로컬에 저장, 즉시 반영.

### 6.19 소셜 계정 연동 `/linked-accounts`
- 행 2개: **이메일 · 비밀번호**, **구글 계정** — 각각 연동됨/안 됨 상태 필
- 구글: "연동하기"(OAuth 링크) / "연동 해제". 마지막 남은 로그인 수단은 해제 불가

### 6.20 데이터 백업 및 복구 `/data-backup`
- **백업하기**: 현재 책 + 갈피를 JSON(§2.6)으로 내보내기. 파일명 `galpi-backup-YYYY-MM-DD.json`. 네이티브는 공유 시트, 웹은 다운로드. 책이 없으면 비활성
- **복구하기**: "파일에서 가져오기"(파일 선택) 또는 "직접 붙여넣기"(텍스트 영역)
- 가져오기 규칙: 페이로드 검증 → 제목+저자 시그니처가 같은 책은 **건너뛰고 기존 책에 갈피를 붙임** → 새 책은 새 ID로 생성(order는 기존 뒤에 이어 붙임) → 갈피는 새 책 ID로 매핑. 이미 동일한 갈피(책·문장·페이지)는 건너뜀. 450개 단위 배치 커밋
- 결과 안내: 추가된 책/갈피 수, 건너뛴 수

### 6.21 공지사항 `/notices`
정적 목록(최신순). 항목: 날짜 · 제목 · 본문. 초기 항목 1개("갈피를 시작합니다", 2026.08.09).

### 6.22 이용약관 `/terms` · 개인정보 처리방침 `/privacy`
정적 섹션 목록(제목 + 본문 단락). 시행일 표기.

## 13. 핵심 사용자 흐름 (회귀 테스트 기준)

1. 온보딩 → 회원가입(약관 동의) → 서재(빈 상태)
2. ＋ → 새 책 추가 → 검색 "데미안" → 추가 → 서재에 표지·장르·총 페이지 반영
3. 책 상세 → 상태 "읽는 중" → 서재 상단 대표 카드에 노출
4. ＋ → 갈피 남기기 → 직접 입력(문장·페이지 120·태그 "위로") → 저장 → 상세에 갈피 + 진행도 갱신
5. 카메라 스캔 → 촬영 → 토큰 선택 → 저장
6. 갈피 즐겨찾기 → `/favorites`에 노출, `/collections`에 "위로" 태그 노출
7. 타이머 25/5 시작 → 다른 화면 이동 시 위젯 표시 → 독서 종료 → 요약 반영 → 서재 오늘 스트립 분 증가, 스트릭 1일
8. 통계 월간: 완독 0 · 갈피 1 · 읽은 날 1, 달력에 오늘 표시 → 리포트 발행 → 이미지 저장
9. 상태 "완독" → `completedAt` 기록 → 뱃지 "첫 완독" 달성 → 마이페이지 `1/12개 달성`
10. 갈피 삭제 → 실행취소 → 복원. 책 삭제 → 실행취소 → 책 + 갈피 복원
11. 백업 내보내기 → 책 삭제 → 복구 → 동일 데이터 복원(중복 없음)
12. 테마 다크 전환, 알림 설정 토글(네이티브), 프로필 수정, 비밀번호 변경, 로그아웃, 회원탈퇴
